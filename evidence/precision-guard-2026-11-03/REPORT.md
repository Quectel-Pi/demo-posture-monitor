# 不良姿势误判为正常：修复与重采记录（2026-11-03）

已部署至当前ADB设备 `/opt/posture-guard/`，后台与桌面UI继续运行。

## 根因与修复

1. 正常兜底只计算距离，没有执行接受范围判断。现在超过正常范围立即 UNKNOWN，清除旧标签与投票；有效常量的零MAD使用最小尺度，不能误当成缺测跳过。非有限特征不参与判定。
2. 原画像样本的基准为10月29日，设备基准已换成11月3日。增加画像 `baseline_id`，绑定标定时间、摄像头、模型和分辨率；缺失或不匹配时停止画像判定并说明重采原因。运行中重新标定也立即失效旧画像。
3. 耳部缺测不能当作测得0度。在具备歪头类别的画像中，缺少可靠耳线或耳线标定时不能确认正常；其他有效特征仍可识别明确的异常。
4. 采样工具原来收不到脸部几何数据，手到脸距离全是缺测。现在状态协议补齐有效标志与距离，采样和实时特征使用相同缺测规则。缺测距离不进入正常统计，避免哨兵扭曲分布。
5. 新样本显示旧顺序把71个托腮训练帧中的35个抢判为歪头。改为过近、托腮、歪头、低头、高低肩的判定顺序，先处理直接距离/手部证据，歪头仍先于低头。所有姿势的阈值重新从本次样本生成。
6. 建模按固定优先级处理，不依赖样本文件遍历顺序。构建拒绝跨标定、重锚旧数据或缺少规则的类别，失败不覆盖现有画像，成功原子替换。重锚不能把旧机位数据改贴成新标定。
